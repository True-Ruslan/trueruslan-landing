# Обо мне

Я Java backend-разработчик с 3+ годами коммерческого опыта. Основной интерес — системы, которые должны быть понятными в развитии, предсказуемыми в эксплуатации и достаточно простыми, чтобы команда могла уверенно их менять.

## Чем я занимаюсь

Работаю с backend-системами и интеграциями: от прикладной бизнес-логики и REST API до баз данных, очередей, контейнеризации и CI/CD.

Мой основной стек включает **Java, Spring Boot, PostgreSQL/Oracle, Redis, Kafka, Docker и OpenShift/Kubernetes**. В отдельных задачах использую Kotlin, Python и JavaScript.

## Как я смотрю на разработку

### Сначала границы, потом код

Хорошая реализация начинается не с количества классов и паттернов, а с понимания ответственности компонентов, источника истины и сценариев изменения системы.

### Надёжность — часть дизайна

Тесты, миграции, наблюдаемость, CI/CD и эксплуатационные ограничения для меня не «инфраструктура вокруг кода», а часть самого инженерного решения.

### AI — инструмент, а не автопилот

Экспериментирую с LLM и агентными системами для анализа кода, автоматизации разработки, прототипирования и работы с большими контекстами. При этом считаю важным сохранять проверяемость результата и контроль над архитектурой.

## Технические интересы

- **Backend:** Java, Kotlin, Spring Boot, API, микросервисы, архитектура.
- **Data:** PostgreSQL, Oracle, ClickHouse, Redis.
- **Integration:** Kafka, event-driven подходы, внешние API.
- **DevOps:** Docker, OpenShift/Kubernetes, Jenkins, GitHub/GitLab CI.
- **AI:** LLM, AI-агенты, tooling и agentic workflows.
- **Game development:** Godot/Unity, архитектура игровых шаблонов и AI-assisted development.

## Вне production-кода

Преподаю разработку и тестирование программных модулей, занимаюсь аспирантским исследованием в области обучения программированию и веду собственный реестр технических материалов, которые изучаю.

Интересуюсь философией, историей, технологиями, путешествиями и фотографией.
