# Engineering Map

Список технологий показывает, **что** человек использовал. Эта карта показывает, **как связаны** технологии, инженерные направления, реальные проекты и выводы, которые из них появились.

engineering-map-build-slot

## Как читать карту

- **Technology** — конкретные инструменты и платформы.
- **Domain** — инженерная область или класс задач.
- **Project** — проект, где связь реализована на практике.
- **Note** — отдельный технический разбор соответствующего решения.

На широком экране карта показывает связи между узлами. На мобильном она превращается в фильтруемый список карточек без потери содержания.

{% note info %}

Карта не является автоматическим рейтингом навыков и не пытается показать «все технологии, которые я когда-либо видел». В ней только связи, которые помогают понять мой текущий инженерный профиль и реальные проекты.

{% endnote %}
